# NailCraft — академия маникюра

Сайт академии NailCraft: лендинг курсов и личный кабинет с онлайн-уроками и записью на офлайн.

**Онлайн:** https://nevxrr.github.io/nailcraft/

## Запуск

```bash
npm install
npm run dev
```

## Что внутри

- Лендинг в стиле референса (hero, курсы, отзывы, контакты)
- Личный кабинет после «оплаты» курса (демо в браузере)
- Онлайн-уроки с прогрессом
- Запись на офлайн-занятия

Предыдущее приложение (СТРОПА) лежит в `archive/stropa-production/`.
